# Dreaming — Landing Page

Landing page para el proyecto Dreaming. Construida con HTML y CSS puro, sin dependencias.

## Estructura

```
.
├── index.html   # Página principal
├── styles.css   # Estilos
└── README.md    # Este archivo
```

## Cómo usar

Abre `index.html` directamente en tu navegador. No requiere servidor ni instalación.

## Secciones

- **Hero** — mensaje principal y llamada a la acción
- **Características** — tres tarjetas con los beneficios del producto
- **Nosotros** — descripción del equipo
- **Contacto** — formulario de contacto
